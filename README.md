# Exo Git Conflit

Petit dépôt de test pour comprendre le mécanisme de collaboration avec Git : clone, commit, push, pull, et résolution de conflit.

## But de l'exercice

Ce dépôt sert à simuler deux membres d'une équipe (Alice et Bob) qui modifient le même fichier en parallèle, afin de provoquer et résoudre un conflit de fusion.

## Étapes prévues

1. Clone du dépôt dans deux dossiers différents (`alice` et `bob`)
2. Modification simultanée de la même ligne
3. Push, échec, pull, conflit
4. Résolution manuelle et push final
5. versiion bob
